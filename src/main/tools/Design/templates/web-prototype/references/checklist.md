# Web 原型自检清单

生成 HTML 前过一遍。P0 = 必须通过；P1 = 应该通过；P2 = 加分项。

## P0 — 必须通过

- [ ] **`:root` 令牌块外没有原始 hex 值。** 每个颜色都是 `var(--bg)` / `var(--fg)` / `var(--muted)` / `var(--border)` / `var(--accent)` / `var(--surface)`（或其 `color-mix()`）。在 `:root{}` 外搜索 `#[0-9a-fA-F]{3,8}` 应该无结果。
- [ ] **所有标题使用 `var(--font-display)`。** 没有无衬线 `<h1>` / `<h2>`。
- [ ] **强调色每屏最多出现两次。** 计数：眉标颜色、主 CTA 填充、还有别的吗？如果三次或以上，将一处降级为 `var(--fg)` 或 `var(--muted)`。
- [ ] **没有紫色/紫罗兰色渐变背景。** 种子模板在背景上没有渐变 —— 保持下去。
- [ ] **不用 emoji 作为特性图标。** 使用布局 3 中的内联 SVG 单线标记，或 `--font-mono` 中的单字符字形。
- [ ] **不编造指标。** 页面上每个数字来自用户或需求，或明确标记为占位符。"10× 更快"、"99.9% 可用性"无来源 = 删除。
- [ ] **无填充文案。** 没有"特性一 / 特性二"、lorem ipsum。如果某个区块感觉空，删除它；不要填充。
- [ ] **每个顶层 `<section>` 上有 `data-od-id`。**
- [ ] **移动端重排有效。** 所有 `grid-2`、`grid-3`、`grid-4`、`grid-2-1`、`grid-1-2` 在 ≤920px 折叠为单列。心理模拟缩小 —— 无水平滚动。

## P1 — 应该通过

- [ ] **一个决定性的点缀。** 一条推荐引言、一个醒目的统计、一张真实感的照片、Hero 上的一个微动画。*一个。* 不是三个。
- [ ] **区块节奏交替。** 不连续两个统计行。不连续两个特性三联。不连续两个引言块。
- [ ] **标题不超过 14 个字。** 如果更长，说明文字在做设计的工作。
- [ ] **引导语不超过 56 字符 / 两句。** `.lead` 上的 `max-width: 60ch` 强制执行；不要覆盖。
- [ ] **CTA 按钮说明会发生什么。** "免费开始"胜过"开始使用"。"阅读故事"胜过"了解更多"。
- [ ] **所有 `<a>` 和 `.btn` 有悬停状态。** 种子模板已覆盖。
- [ ] **数字使用 `.num`（等宽，表格数字）。** 价格、统计、版本号、日期。
- [ ] **每页一种图片风格。** 不要混合方形人像头像、宽屏产品 Hero 和竖屏手机截图 —— 选一种。

## P2 — 加分项

- [ ] **`text-wrap: pretty` / `balance`** 在长段落/标题上（种子已在 `<p>` 和 `h*` 上设置）。
- [ ] **`color-mix()` 派生色调。** 不添加额外的 `--accent-50` / `--accent-300` Bootstrap 风格令牌 —— 当场派生。
- [ ] **粘性顶部导航有毛玻璃效果**（种子已通过 `backdrop-filter: blur()` 实现）。
- [ ] **字体系统优先。** Iowan Old Style / Charter 作为衬线，系统栈作为无衬线。

## 反套路抽查

看页面两秒。如果你的直觉说以下任何一条：

- "看起来像我这月见过的每个 AI 创业公司首页"
- "这可能是任何 SaaS 的官网"
- "特性行有图标、标题和三行模糊的好处描述"

……回去，把一个特性单元格换成更具体的东西（截图、具体例子、实际输出样本），并去掉一个强调色。
