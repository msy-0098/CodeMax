# 移动应用自检清单

生成 HTML 前过一遍。P0 必须通过。

## P0 — 必须通过

- [ ] **设备框看起来像手机，不是普通卡片。** 灵动岛可见，状态栏 SVG 图标存在（信号/WiFi/电池），底部有 Home 指示器。种子已做这些 —— 验证你没有意外删除岛/侧边按键/指示器标记。
- [ ] **状态栏显示真实字形**，不是 `· · · 5G · 100%` 这样的文字。使用种子中的 SVG 图标。
- [ ] **Home 指示器是最后可见的元素。** 它下面的任何东西（如额外 padding、意外的 `<div>`）都会破坏错觉。
- [ ] **内容滚动，设备框不动。** `<main class="content">` 有 `overflow-y: auto`；外围 `.device` 没有。页面背景永不移动。
- [ ] **点击目标 ≥ 44px 高。** 种子的 `.btn-primary`（48px）、`.tab`（~50px）、`.icon-btn`（36px ≥ 含 padding 的触摸区）、`.list-row`（≥48px 含 padding）都通过。不要发布低于 44px 的按钮。
- [ ] **正文 ≥ 14px。** `--fs-body: 15px` 已在大多文案上强制执行。列表行副文字最多 13px —— 那是下限。
- [ ] **一个强调色，屏幕上最多用两次。** 典型：一个活跃标签 + 一个 CTA，或一个强调色卡片 + 一个标签。绝不超过三次。
- [ ] **无外部图片 URL。** 使用 `.ph-img` 占位符类。外部 CDN 图片会 404 时看起来很假。
- [ ] **标签栏匹配界面类型。** Onboarding / Detail / Checkout：删除整个 `<nav class="tabbar">`。Feed / Focus / Profile：保留。
- [ ] **标题使用 `var(--font-display)`（衬线体）。** 种子通过 `.h1`、`.h2`、`.header h1` 绑定。不要覆盖标题为系统无衬线 —— 那会立刻看起来像库存模板。
- [ ] **UI 中无 emoji 图标。** 仅 SVG 单线。文案中的 emoji 可以。
- [ ] **设备、内容、头部和主要区域有 `data-od-id`。**

## P1 — 应该通过

- [ ] **一屏一事。** 个人资料界面做个人资料的事。不要把结算表单嫁接到 feed 上。
- [ ] **设备上方的说明** 命名了界面（如"FILEBASE · 收件箱"）。种子已有槽位 —— 填上。
- [ ] **状态栏时间是 `9:41`**（Apple 惯例），除非需求另有要求。
- [ ] **数字用等宽字体** —— 计数、价格、时长、日期。种子的 `.num` 类绑定此。
- [ ] **真实、具体的文案。** "张明 · CTO"胜过"用户名"。"¥13,440"胜过"¥X,XXX"。
- [ ] **首屏内容在 844px 框架内** 不需要滚动即可看到主要操作。如果 CTA 在折叠线以下，说明选错了布局。

## P2 — 加分项

- [ ] **页面背景上有微妙的强调色径向渐变**（种子已实现）。移除它会让设备感觉贴在平面上。
- [ ] **标签栏有背景模糊**（种子已通过 `backdrop-filter` 实现）。
- [ ] **每屏最多一个图片占位符。** 小画布上两个占位符争夺注意力。
- [ ] **边框上有微妙的金属侧边导轨**（种子已通过 `::before`/`::after` 实现）。

## 反假设备清单

如果以下任何一条为真，界面看起来像*假装是手机的卡片*而不是手机：

- 设备外角没有明显比内屏更圆（~56px vs ~44px）。
- 顶部中央没有灵动岛缺口。
- 状态栏文字是灰色或低透明度（应该是 `var(--fg)` 全强度）。
- Home 指示器缺失。
- 底部标签栏没有上边框或没有背景模糊。

种子防止了所有这些 —— 最常见的回归是 Agent 用 `border-radius: 24px` 重写设备框并丢失了深度。
